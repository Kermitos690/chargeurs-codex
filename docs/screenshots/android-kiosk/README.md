# Preuves visuelles Android kiosk

Les écrans d'activation, de splash et de fallback sont compilés dans
`Chargeurs_CH_Kiosk_1.0.4-staging.apk`. Aucune capture présentée comme issue
d'une tablette réelle n'est fournie ici : aucune tablette ni émulateur n'était
connecté pendant ce build.

La preuve disponible est le build vérifié, le lint et les tests unitaires. Les
captures suivantes doivent être ajoutées après la recette physique, sans code
d'activation réel, jeton, email ni identifiant de client : splash, activation,
accueil, QR Stripe test, hors ligne et diagnostics.
